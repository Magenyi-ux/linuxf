## 2025-05-15 - [XSS Protection in KaTeX Rendering]
**Vulnerability:** Cross-Site Scripting (XSS) via `dangerouslySetInnerHTML` when rendering LaTeX content with KaTeX. Older versions of KaTeX (0.16.9 and below) had specific vulnerabilities that allowed protocol bypass and unescaped filenames.
**Learning:** Even well-established libraries like KaTeX can produce complex HTML, SVG, and MathML that may contain XSS vectors if the input is not strictly controlled. Simple injection into the DOM without sanitization is a high-risk pattern.
**Prevention:** Always use a specialized sanitizer like `DOMPurify` with the appropriate profiles (`html`, `svg`, `svgFilters`, `mathMl`) when injecting HTML generated by libraries into the DOM. Keep security-sensitive dependencies like KaTeX up to date.
