## 2026-03-31 - [KaTeX XSS Protection with DOMPurify]
**Vulnerability:** KaTeX version 0.16.9 (and earlier) has several moderate vulnerabilities, including a bypass for forbidden protocols in URLs and incomplete escaping of filenames in `\includegraphics`. These can lead to Cross-Site Scripting (XSS) if untrusted input is rendered.
**Learning:** KaTeX generates HTML strings that are typically injected into the DOM using `dangerouslySetInnerHTML`. While KaTeX does some internal sanitization, it's not a full-featured HTML sanitizer. Relying solely on a math library for security is insufficient.
**Prevention:** Always use a dedicated, robust HTML sanitizer like `DOMPurify` to clean any HTML generated by third-party libraries before injecting it into the DOM. Keep security-critical dependencies like KaTeX updated to versions that address known vulnerabilities (e.g., 0.16.44).
