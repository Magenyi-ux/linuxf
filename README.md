

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Configure environment variables:
   - Copy `.env.example` to `.env`
   - Set `VITE_NVIDIA_API_KEY` and `NVIDIA_API_KEY` to your NVIDIA API key
   - Set `GEMINI_API_KEY` if using legacy features
3. Run the app:
   `npm run dev`
