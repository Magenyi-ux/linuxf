# Examply - West African Exam Prep

**Prerequisites:** Node.js (v20+)

1. Install dependencies:
   `npm install`
2. Configure environment variables:
   - Copy `.env.example` to `.env`
   - Set `VITE_NVIDIA_API_KEY` to your NVIDIA NIM API key.
3. Run the app:
   `npm run dev`

## Deployment
The app is configured for Vercel. Ensure you set the `VITE_NVIDIA_API_KEY` environment variable in your Vercel project settings.
